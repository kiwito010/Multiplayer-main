# Signal Lost

Proyecto Unity en C# con fecha de entrega cercana.

## Reglas de trabajo

- No modificar nada de multiplayer/networking.
- No tocar `NetworkManagerFusion`, `PlayerMovement`, `PlayerCameraSwitch`, `PlayerNetworkInteraction` ni otros archivos del flujo multijugador.
- Priorizar los sistemas locales que estoy desarrollando: Engineer, Explorer, Computer/Hacker, tareas, UI e interacciones.
- No modificar escenas, prefabs o configuraciones de Unity sin pedir permiso.
- No hacer refactors grandes sin autorización.
- Mostrar el diff antes de aplicar cambios importantes.
- Mantener el código simple y entendible.
- Priorizar terminar funcionalidades esenciales sobre polish.
- No agregar sistemas nuevos innecesarios.
- Antes de cambiar APIs usadas por varios scripts, revisar todas sus referencias.
- Si un cambio requiere tocar multiplayer, avisar y no hacerlo.
